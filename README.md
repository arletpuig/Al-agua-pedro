# AL AGUA PEDRO

Juego web satírico: consigue tomates haciendo clic y lánzalos para tirar a Pedro a la piscina.

## Ejecutar en local
No necesita instalación. Abre `index.html` con un servidor estático, por ejemplo:

```
npx serve .
```

o `python3 -m http.server 8080` y entra en http://localhost:8080

## Tecnología
HTML + CSS + JavaScript (módulos ES), SVG animado, Web Audio API. Sin dependencias ni paso de build.
